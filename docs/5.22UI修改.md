## 3\. 关键技术决策

1. **背景视频**：用 `<video autoPlay loop muted playsInline>` 加 fixed 定位。两个 mp4 文件作为 `<source>` 多源 fallback。叠加深色径向 + 线性渐变保证文字对比度。
2. **切角效果**：不用 `clip-path`，统一用 webp 边框图做 `background-image: 100% 100%`，避免不同尺寸卡片切角弧度不一致。
3. **字体回退**：Alibaba PuHuiTi 加载失败时回退到系统 PingFang SC / 微软雅黑，绝对不退到 system-ui。
4. **配色硬编码**：DASHBOARD\_COLORS 全部用 hex 而非 oklch，方便复制到 SVG `fill`/`stroke`。

## 5\. 已知风险与待确认事项

1. **背景视频性能**：两段 mp4 加起来约 25MB。在低端机器上首次加载会卡。可以考虑：

   * 用 `<video poster="...">` 先显示一张静态首帧
   * 或者把视频放在 `<details>`/按需懒加载
2. **切角边框拉伸**：webp 边框被 `background-size: 100% 100%` 强行拉伸，**长宽比极端**（如表格区）时切角会变形。如果发现某个区块切角变椭圆，需要换成 CSS `clip-path` 或者 9-slice 切图。
3. **图表系列色一致性**：DASHBOARD\_COLORS.series 只有 5 个色。如果某个图表需要超过 5 类，需要扩展或循环。
4. `Image`\*\* 与 \*\*`webp`：`dashboard-primitives.tsx` 里 `<CornerPiece>` 用了 `next/image`，需要确认 `next.config.js` 已经允许 webp（Next 默认就支持，但需要确认 `unoptimized` 是否禁用了优化）。
