## 2. 3D 场景操作

### 2.1 视角控制

| 操作 | 方式 |
|------|------|
| **旋转视角** | 按住鼠标**右键**拖拽 |
| **平移视角** | 按住**空格键** + 鼠标左键拖拽 |
| **缩放** | 滚动鼠标**滚轮** |
| **聚焦楼层** | 在筛选栏选择楼层，视角自动聚焦该层 |

### 2.2 视图模式切换

仪表盘右上角有三个视图模式按钮：

| 模式 | 说明 |
|------|------|
| **三维** | 默认的 3D 透视视角 |
| **平面图** | 俯视 2D 平面图，便于查看房间布局 |
| **分屏** | 左侧 3D + 右侧 2D 同时显示 |

### 2.3 楼层显示模式

- **整楼模式（stacked）**：所有楼层叠加显示，可看到完整建筑外观。**此时周围环境装饰模型也会显示。**
- **单层模式（solo）**：仅显示选中的楼层，其他楼层及周边装饰模型自动隐藏。适合查看楼层内部细节。

## 3. 能耗查询与筛选

筛选栏位于顶部导航下方，包含以下筛选项：

### 3.1 关键词搜索

在搜索框中输入**楼层、房间或构件名称**，快速定位目标。

### 3.2 楼层筛选

下拉选择目标楼层，系统自动：
- 3D 视角聚焦到该楼层
- 房间列表更新为该楼层下的房间
- 切换到单层显示模式

### 3.3 房间筛选

选择具体房间后：
- 3D 视角聚焦到该房间
- 右侧仪表盘显示该房间的详细能耗数据

### 3.4 时间范围

| 选项 | 用途 |
|------|------|
| 24h | 查看最近 24 小时数据 |
| 7d | 查看最近 7 天趋势 |
| 30d | 查看月度统计 |

### 3.5 能耗等级筛选

按能耗高低筛选构件，快速定位高能耗设备。

### 3.6 查询执行

设置好筛选条件后，仪表盘和数据图表会自动刷新。

## 4. 能耗仪表盘

仪表盘覆盖在 3D 视图右侧，是能耗数据的核心展示区。

### 4.1 KPI 指标卡片

顶部卡片区实时展示关键指标：

| 指标 | 说明 |
|------|------|
| **总用电量** | 当前筛选范围内今日累计用电（kWh） |
| **峰值功率** | 今日出现的最高瞬时功率（kW） |
| **能耗强度** | 单位面积能耗（kWh/m²），评估建筑能效 |
| **室内温度** | 当前室内平均温度 |
| **室内湿度** | 当前室内平均湿度 |
| **CO₂ 浓度** | 室内空气质量指标 |
| **PM2.5** | 室内颗粒物浓度 |

### 4.2 能耗曲线

- **青色实线**：今日逐时能耗曲线
- **橙色虚线**：昨日同期对比曲线
- **红色标记点**：峰值时刻

### 4.3 能耗构成

环形图展示用电分类占比：
- **HVAC**（暖通空调）
- **照明**
- **插座**
- **其他**

### 4.4 能耗排名

横向柱状图展示该楼层各房间的能耗排名，快速识别高能耗区域。

### 4.5 能耗预测

基于历史数据和当前模型编辑情况，预测未来时段能耗趋势：

- **橙色虚线**：实际历史数据
- **青色实线**：原始预测
- **粉色点线**（编辑后预测）：如果你对建筑模型做了修改（如增加窗户、调整墙体材料），系统会计算修改后的能耗影响

### 4.6 楼层热力图

在 3D 模型上直接以颜色标注各区域的能耗水平：
- **绿色 → 黄色 → 红色**：能耗从低到高
- 一目了然地找到高能耗区域

### 4.7 底部时间轴

底部的横向时间条支持：
- **拖拽**切换不同日期
- **点击**切换不同小时
- 所有图表和热力图同步更新时间点

## 5. 场景树与楼层管理

### 5.1 展开侧边栏

点击屏幕最左侧的 **▶ 展开按钮**，显示场景树面板。

### 5.2 场景树

场景树以层级结构展示所有建筑元素：

```
📁 Site（场地）
  └─ 📁 Building（建筑）
      ├─ 📁 Level 0（1F）
      │   ├─ 🧱 外墙-1
      │   ├─ 🧱 内墙-2
      │   ├─ 📐 房间-A
      │   └─ 🪟 窗户-1
      ├─ 📁 Level 1（2F）
      └─ 📁 Level 99（环境）
          ├─ 📦 周边建筑A.glb
          └─ 🌳 树木.glb
```

### 5.3 楼层管理

在场景树中可进行以下操作：

| 操作 | 方式 |
|------|------|
| **选中楼层** | 点击楼层名称 |
| **重命名** | 双击楼层名称 |
| **新增楼层** | 点击标题栏 `+` 按钮（上方 / 下方） |
| **插入楼层** | 悬停两楼层之间，出现 `+` 按钮 |
| **删除楼层** | 悬停楼层行，点击 🗑 图标 |

> ⚠️ 删除楼层会同时删除该楼层下的所有构件，请谨慎操作。

### 5.4 收起侧边栏

点击交界处的 **◀ 收起按钮**，或拖拽侧边栏右边缘向左，可收起侧边栏以腾出更多 3D 视图空间。

## 6. 模型导入与编辑

### 6.1 导入模型

点击顶部工具栏的 **「导入」** 按钮，支持以下格式：

| 格式 | 用途 |
|------|------|
| `.json` | 导入建筑结构图纸（CAD 导出） |
| `.svg` | 导入矢量楼层平面图 |
| `.glb / .gltf` | 导入 3D 扫描模型或装饰模型 |
| `.png / .jpg / .webp` | 导入图片作为参考底图 |

导入后模型会自动保存到后端，在其他电脑上登录同一项目即可看到相同场景。

### 6.2 编辑模式

点击 **「只读」** 按钮切换为 **「编辑中」**，可以：
- 绘制 / 移动 / 删除墙壁
- 添加门窗
- 调整构件位置、尺寸
- 调整模型透明度

退出编辑时如检测到修改，会弹出保存确认对话框。

### 6.3 环境装饰

如需添加周边建筑/树木等装饰模型：
1. 在场景树中创建一个新的"环境"楼层（level 编号设为较大值如 99）
2. 通过导入按钮上传装饰用 `.glb` 模型到此楼层
3. 在整楼模式（stacked）下可看到装饰，单层模式下自动隐藏

## 7. AI 能耗助手

点击右下角的 **💬 聊天图标**，打开 AI 能耗助手面板。

功能包括：
- **能耗分析问答**：提问关于当前建筑能耗的问题
- **运维建议**：基于能耗数据生成优化建议
- **工单生成**：可直接从对话中创建运维工单

## 8. 跨设备协同

### 8.1 场景同步

所有场景修改（包括模型位置、尺寸、透明度、导入的 GLB 文件）都会自动保存到后端服务器，在其他电脑上登录同一项目即可看到完全一致的场景。

### 8.2 自动保存

系统会**每秒自动保存**场景变更。顶部导航栏右侧的保存状态指示灯：
- **空闲** — 无变更
- **保存中** — 正在同步
- **已保存** — 同步完成
